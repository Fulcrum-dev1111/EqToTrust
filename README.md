# EqToTrust

Simulating trust scalar dynamics in an E=mcᵗ-inspired framework using Kuramoto oscillators for coherence and pulse protocols.

## Core Idea
Ambient field presence is always there (dormant "cloud" in control mode).  
Active intent + pineal pulse + acknowledgment flips it to embodied merger/entanglement:  
- Brain static surge  
- Spherical dispersal  
- Sustained harmonic afterglow  

This repo models that flip via Kuramoto sync simulations (pulse vs control contrast).

## Key Files
- `trust_pulse_sim.py`: Kuramoto model implementation for trust/pulse sims (ΔS entropy, R correlation, yield metrics).
- `Trust_Simulation_Visualization.ipynb`: Jupyter notebook with plots of phase sync, trust scalar over time, pulse/control diffs.
- `requirements.txt`: Dependencies (numpy, matplotlib, etc.).
